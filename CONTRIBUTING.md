# Как участвовать в Additive Light / GDI

Спасибо, что интересуешься проектом! Additive Light — исследовательский (R&D) репозиторий под лицензией MIT. Мы рады идеям, баг-репортам и pull request'ам, но из-за специфики генеративного CAD просим сначала обсудить крупные изменения.

---

## 🚀 Быстрый путь

1. **Форкни** репозиторий.
2. **Создай ветку** от `main`:
   ```bash
   git checkout -b feature/краткое-описание
   ```
3. **Сделай изменения.** Придерживайся минимального diff и KISS.
4. **Запусти проверки качества:**
   ```bash
   pytest tests/ -v
   black gdi_core/ gdi_app/ web/
   mypy gdi_core/
   ```
5. **Обнови документацию**, если менялась архитектура или публичный API (`README.md`, `ARCHITECTURE.md`, `CHANGELOG.md`, `AGENTS.md`).
6. **Открой PR** с понятным описанием: что сделано, зачем, как проверялось.

---

## 🎨 Стиль кода

- **Python:** PEP 8, `black`, аннотации типов — там, где это не усложняет.
- **JS/CSS:** придерживайся существующего стиля `script.js` / `style.css`.
- **Коммиты:** конкретные, на русском или английском (как основной язык задачи).
  - Примеры: `feat: добавить retry для OpenRouter`, `fix: исправить автоцентрирование камеры Three.js`.

---

## 🚫 Что нельзя коммитить

- `.env`, `*.pem`, `id_*`, токены, пароли, `github_pat_*`.
- `node_modules/`, `__pycache__/`, `.venv/`, `venv/`.
- Бинарный `openscad.wasm` (см. `.gitignore`).
- Локальные артефакты: `output/`, `logs/`, `test_output/`.

---

## ✅ Definition of Done для PR

- [ ] Код релевантен задаче; diff минимален.
- [ ] Тесты проходят (`pytest tests/ -v`) или добавлены новые.
- [ ] Код отформатирован (`black gdi_core/ gdi_app/ web/`).
- [ ] Типизация проверена (`mypy gdi_core/`), по возможности.
- [ ] Секреты не утекли.
- [ ] Документация обновлена при необходимости.
- [ ] В PR описаны: цель, что изменилось, как проверялось.

---

## 💬 Обсудить до кода

Открой issue или обсуди в существующей задаче, если планируешь:

- крупные изменения архитектуры (например, замена OpenSCAD WASM, новый AI-провайдер);
- изменения публичного API (`gdi_core/api.py`, YAML-контракт);
- prod-деплой и работу с ключами.
