# Bench Inventory

Snapshot of every STL currently present in `benchmark_kit/`, `tests/fixtures/`
and how it maps to the deterministic revolution-body pipeline.

Source raw metrics: [temp/sprint1_inventory.json](../temp/sprint1_inventory.json)
(auto-generated by Sprint 1.1). Manual category column corrects the few cases
where the rotational-symmetry heuristic gives a misleading value (n-fold
symmetric features still register as high `sym` even when the part is not a
body of revolution).

Categories (used elsewhere in the roadmap):

- `revolution_pure` — single body of revolution; pipeline must reconstruct
  it without flagging any out-of-scope region.
- `revolution_with_features` — revolution body with localised non-revolution
  features (keyway, cross-hole, flat, etc.); pipeline reconstructs the
  revolution part and flags the rest as a `SkillRequest` (Sprint 3).
- `non_revolution` — not a body of revolution at all; pipeline should
  produce low confidence and emit `SkillRequest` covering most of the part.
  Used as negative controls and as fuel for the swarm v2 roadmap.
- `corrupt` — intentionally broken meshes; validate error handling.
- `fixture` — small synthetic test fixtures bundled with the unit-tests.

`sym` is the rotational-symmetry score (0–1) from the inventory script.
`L/D` is length-to-diameter ratio along the principal axis (a quick proxy
for "long shaft" vs "short disc").

## Sprint 1.3 gaps (parts to generate)

These are the bodies of revolution that are **missing** from the bench
above and that Sprint 1.3 will add via
[scripts/generate_benchmark_stl.py](../scripts/generate_benchmark_stl.py):

- `hourglass_shaft.stl` — concave "diabolo" profile; PCA-stable but exercises
  the `fit_arc` path for concave segments.
- `chamfer_shaft.stl` — stepped shaft with explicit 30°/45°/60° chamfers;
  golden test for `_build_revolve_polyline` arc discretisation (Sprint 2.4).
- `fillet_shaft.stl` — stepped shaft with explicit R0.5 / R2 / R5 fillets;
  CAD-drawn version of `tests/fixtures/shaft_with_fillet.stl` with known
  ground truth.
- `conical_shaft.stl` — cone + cylinder + cone; targets `fit_cone`.
- `barrel_shaft.stl` — barrel-shaped (spline generatrix); targets the
  currently stubbed spline-zone path.
- `short_disc_shaft.stl` — `L ≈ D`; targets the PCA edge case noted in
  Sprint 0 acceptance criteria.
