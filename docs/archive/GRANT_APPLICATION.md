# Описание проекта для конкурса «Старт-ИИ-1» (Фонд содействия инновациям)

**Название проекта:** Разработка гибридной кроссплатформенной среды «Additive Light» для генерации параметрических 3D-моделей и подготовки управляющих программ аддитивного производства на основе моделей искусственного интеллекта.

---

## 1. Аннотация проекта

Проект направлен на создание универсальной программной экосистемы для генеративного 3D-моделирования, объединяющей преимущества облачных технологий и локальных вычислений. Система «Additive Light» реализует концепцию "Text-to-CAD" (Текст-в-Модель) и состоит из двух взаимодополняющих модулей:
1.  **Web-версия (Zero-Install):** Доступна из любого браузера, использует WebAssembly для клиентских вычислений, не требует установки ПО. Идеальна для обучения и быстрого прототипирования.
2.  **Desktop-версия (High-Performance):** Локальное приложение для профессионального использования, обеспечивающее максимальную производительность, работу без доступа к интернету и интеграцию с локальными слайсерами.

Ключевая инновация — использование больших языковых моделей (LLM) для генерации валидного инженерного кода (SolidPython/OpenSCAD) вместо полигональных сеток, что гарантирует конструкционную точность изделий.

---

## 2. Проблема и решение

**Проблема:**
*   Высокий порог входа в CAD-системы: необходимость долгого обучения и дорогостоящие лицензии.
*   Ограниченность существующих онлайн-генераторов: они создают "артистичные", но технически некорректные модели (незамкнутые контуры, артефакты сетки).
*   Зависимость от облачных сервисов: невозможность работы с конфиденциальными чертежами на сторонних серверах и зависимость от интернета.

**Решение — Гибридная платформа Additive Light:**
*   **Два режима работы:** Пользователь выбирает между легкостью доступа (Web) и мощностью/приватностью (Desktop).
*   **Генеративный инжиниринг:** Пользователь описывает задачу на естественном языке ("Корпус для Arduino с вентиляцией"), а AI пишет программу для её построения.
*   **Локальность данных:** В Desktop-версии все данные и (опционально) модели ИИ могут работать локально, обеспечивая защиту интеллектуальной собственности (IP).

---

## 3. Научно-техническая новизна

Проект предлагает уникальную архитектуру, отсутствующую у конкурентов:

1.  **Семантическая генерация кода (Code-as-intermediary):** Использование LLM для синтеза скриптов SolidPython2. Это обеспечивает 100% повторяемость, редактируемость и параметризацию моделей.
2.  **Гибридная Edge-Cloud архитектура:**
    *   В Web-версии используется **WASM-пайплайн** (Pyodide + OpenSCAD WASM), переносящий нагрузку с сервера на устройство пользователя.
    *   В Desktop-версии реализован **Native-пайплайн** с прямым доступом к ресурсам ОС и GPU для рендеринга сложных сборок.
3.  **Агностичность к ИИ-моделям:** Система спроектирована как "оболочка", способная работать как с облачными API (OpenRouter, YandexGPT), так и с локальными открытыми моделями (через Ollama/Llama.cpp) в десктоп-версии.

**Направление ИИ (согласно классификатору):**
*   Компьютерное зрение (в перспективе для генерации по эскизам).
*   Обработка естественного языка (генерация кода).
*   Системы поддержки принятия решений (автоматическая оптимизация под 3D-печать).

---

## 4. Техническая реализация (Стек технологий)

Проект представляет собой монорепозиторий, включающий два клиента с общей логикой промпт-инжиниринга:

**А. Web-клиент (Клиентская сторона / Frontend):**
*   **Ядро:** JavaScript (ES6+), Web Workers.
*   **Вычисления:** Pyodide (Python в браузере), OpenSCAD WASM (рендеринг C++ в WASM).
*   **Визуализация:** Three.js / WebGL.
*   **Преимущество:** Работает на планшетах, Chromebook и слабых ПК без установки.

**Б. Desktop-клиент (Локальная сторона):**
*   **Ядро:** Python 3.10+.
*   **GUI:** CustomTkinter / PyQt (современный адаптивный интерфейс).
*   **Вычисления:** Нативный OpenSCAD, локальный Python-интерпретатор.
*   **Преимущество:** Работа с большими сборками, отсутствие лимитов памяти браузера, работа офлайн, прямая интеграция с файловой системой и слайсерами.

## 5. План выполнения НИОКР (Календарный план)

**Этап 1: Унификация архитектуры (0-3 мес)**
*   Создание единого ядра генерации промптов для Web и Desktop версий.
*   Оптимизация WebAssembly-сборки OpenSCAD для повышения скорости в браузере.
*   Релиз стабильной Desktop-версии с инсталлятором для Windows/Linux.

**Этап 2: Интеллектуализация и Автономность (4-6 мес)**
*   Разработка модуля "Локальный Интеллект" для Desktop-версии (интеграция с локальными LLM для работы без интернета).
*   Внедрение системы автоматического исправления ошибок кода (Self-Healing Code).
*   Реализация библиотеки параметрических пресетов (Галерея шаблонов).

**Этап 3: Экосистема и Внедрение (7-12 мес)**
*   Интеграция с популярными слайсерами (плагин для прямой передачи модели на печать).
*   Запуск облачного репозитория пользовательских промптов и моделей.
*   Пилотное внедрение в образовательных учреждениях (ЦМИТ, Кванториумы).

---

## 6. Коммерциализация и Рынок

**Целевые сегменты:**
1.  **Образование (EdTech):** Web-версия для классов информатики и технологии (не требует администрирования и установки ПО).
2.  **Профессионалы (Prosumers):** Desktop-версия для инженеров и мейкеров, требующих конфиденциальности и производительности.
3.  **Корпоративный сектор:** Локальное развертывание (On-premise) для конструкторских бюро.

**Потенциал импортозамещения:**
Проект является полностью отечественной разработкой, способной заменить базовый функционал зарубежных CAD-систем (Autodesk Fusion 360, Tinkercad) в нише быстрого прототипирования, используя открытый исходный код и независимые от санкций технологии.
