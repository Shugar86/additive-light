  ADDITIVE LIGHT & OpenSCAD AI: БЫСТРЫЙ СТАРТ
═══════════════════════════════════════════════════════

Проект объединяет два инструмента в одной папке:
1. Веб-версия (Additive Light) — генератор 3D-моделей в браузере.
2. Десктоп-версия (OpenSCAD AI) — GUI-ассистент на Python.

ТРЕБОВАНИЯ:
-----------
- Установленный Python 3.10+ (обязательно добавьте в PATH при установке)
- Браузер (Chrome/Edge/Firefox)
- Интернет (для работы AI)

═══════════════════════════════════════════════════════
  ЗАПУСК ВЕБ-ВЕРСИИ (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════

1. Найдите файл `start-server.bat` в папке.
2. Запустите его двойным кликом.
3. Откроется консоль сервера. НЕ ЗАКРЫВАЙТЕ ЕЁ.
4. Откройте браузер по адресу: http://localhost:8001

(Если батник не работает, откройте консоль и введите: python server.py)

═══════════════════════════════════════════════════════
  ЗАПУСК ДЕСКТОП-ВЕРСИИ
═══════════════════════════════════════════════════════

1. Найдите файл `start-desktop.bat` в папке.
2. Запустите его двойным кликом.
3. Откроется окно приложения OpenSCAD AI.
